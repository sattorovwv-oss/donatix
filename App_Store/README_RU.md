# Материалы App Store

В этом комплекте есть приложение iOS, иконка 1024×1024 и release workflow.
App Store Connect ещё не заполнен, скриншоты настоящего приложения и результаты
проверки на iPhone отсутствуют. Инструкция сборки: ../IOS_SETUP_RU.md.

Название: Donatix. Предлагаемый subtitle: «Игры и цифровые сервисы».
Описание: Donatix позволяет просматривать каталог цифровых товаров, оформлять
заказы, отслеживать результат выдачи и историю операций, обращаться в поддержку
и управлять аккаунтом. Доступные товары, цены и способы расчёта определяются сервером сервиса.

Контакт поддержки и URL политики должны вести на действующий сервер владельца.
Удаление аккаунта доступно в приложении и на /account-deletion. Для проверки предоставить
работающий аккаунт с нужными правами и объяснить порядок одобрения новых партнёров.
Не указывать фиктивные доступы, сведения о компании или результаты проверки.

## Инвентаризация данных для владельца

| Данные | Назначение |
|---|---|
| Email, логин, user ID, Google/Apple subject | Вход, профиль, права |
| ID устройства, push token | Доставка уведомлений по разрешению |
| Заказы, суммы, баланс, возвраты | Реальные операции и история |
| Фото/PDF чеков | Проверка пополнения |
| Введённые получатели, username, служебные настройки ботов/API | Выполнение заказов и функций сервиса |
| IP/время входа и серверный журнал запросов | Работа сервиса и безопасность |

PrivacyInfo.xcprivacy описывает используемые нативные API и известные категории
данных. Ответы App Privacy в App Store Connect владелец должен согласовать с
фактическим сервером, поставщиками, Firebase и опубликованной политикой.
Tracking/рекламные SDK в этот клиент не добавлялись.

## Выпуск

Использовать ios-release и App Store профиль владельца. Скриншоты снимать с настоящего
собранного приложения на нужных iPhone/iPad. Указать реальные права на каталог/бренд.
Проверить App Review Guidelines 3.1, 4.8 и 5.1: схема исходных внешних оплат цифровых
товаров ещё не принята App Store. StoreKit/In-App Purchase в этом комплекте не реализованы;
не заявлять готовность такой схемы к публикации без проверки её применимости.

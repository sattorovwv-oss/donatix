# Donatix: поддержка и изображения пакетов

Поддержка в приложении использует действующую страницу `/panel/support` с текущей сессией аккаунта. Для получения кода и открытия Telegram не нужен отдельный мобильный модуль. Кнопка отправки кода в уведомления использует существующую форму сайта с CSRF. После возврата из уведомлений приложение получает новую ссылку, поскольку выдача нового кода отзывает предыдущий.

В карточках алмазов и ваучеров добавлены встроенные изображения с прозрачным фоном. Они доступны без загрузки из интернета. Название, регион и точная цена размещены рядом с картинкой. Кнопка корзины и переход к покупке сохранены. Для UC, прокачки и остальных товаров остаются обложки поставщика; изображения алмазов не подставляются для другой валюты.

Для установки обновления запустите существующий workflow `android-release` в Bitrise с веткой `main`, затем установите APK из новой сборки. Новые секреты и изменения сервера для этого обновления не требуются.

На телефоне проверьте: «Ещё → Поддержка» → открыть Telegram; получить код в уведомления и вернуться; открыть Free Fire, выбрать алмазы/ваучер и добавить пакет в корзину.

Проверки на Flutter 3.35.4: `flutter analyze` без замечаний, все 92 Flutter-теста и 26 Python-тестов подготовки release прошли. Дополнительно проверено отображение новых экранов на ширине 360 px с масштабом текста 1.4. Открытие Telegram с настоящим аккаунтом нужно проверить на телефоне после установки новой сборки.

Изображения созданы встроенным ImageGen: три объёмных голубых алмаза и золотой ваучер со звездой, без надписей, на прозрачном фоне. Оптимизированные ассеты: `Donatix_Flutter/assets/products/diamonds.webp` и `Donatix_Flutter/assets/products/voucher.webp`.

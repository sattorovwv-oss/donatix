# Donatix: совместимость дополнения с текущим сервером, версия 9.1

Это обновление поверх уже применённого Android v9 (коммит пользователя `4dc3e3b`). Оно исправляет остановку установщика на `donatix/app.py`: дополнение сверено с Python-модулями, полученными с сервера 9 октября 2026 года. Проверка версии сохранена; неизвестные дальнейшие изменения снова остановят установку.

## Что изменено

- История выполняет те же запросы и фильтры обработчика сайта, но получает JSON без рендеринга HTML. Глобальный обработчик и шаблоны сайта не изменяются.
- Удаление очищает гостевые ключи, данные покупок в `payments.intent`, переписку новой поддержки, её скриншоты и голосовые файлы. Старые обращения получают пустые закрытые записи с зарезервированными номерами, чтобы ответы на старые сообщения Telegram не попали к другому клиенту.
- Записи поддержки и их очистка синхронизируются по аккаунту. После очистки старый ответ или создание обращения для удалённого аккаунта отклоняются.
- Оплаченная, но ещё обрабатываемая покупка, незавершённый заказ и денежный остаток задерживают очистку до завершения расчётов. Автоматических возвратов или списания остатка дополнение не выполняет.
- Платёжные идентификаторы, включая `ext_id`, остаются для защиты от повторного зачисления. Пустые номера уведомлений сохраняются и после ежедневной уборки сайта, чтобы push остальных клиентов продолжал работать.
- Общий файл или кэш игрока, на который ссылается другой аккаунт, сохраняется для этого аккаунта. Другие клиентские записи и суммы не изменяются.

Установщик заменяет только `factory.py`, `history.py`, `erasure.py` в `/opt/donatix-android-addon/v1/donatix_android_extension`. Существующий вариант Google-входа сохраняется. Исходники сайта, `.env`, Firebase-ключ, nginx, конфигурация systemd и схема основной базы этим обновлением не переписываются. Состояние удаления хранится в отдельной базе Android-дополнения. Основная база изменяется при явном запросе удаления владельцем аккаунта.

## 1. Обновить папку проекта и GitHub

Скачайте `Donatix_Server_Fix_v9_1.zip` в Загрузки или на рабочий стол. В Windows PowerShell:

```powershell
& {
    $ErrorActionPreference = "Stop"
    $zip = Get-ChildItem "$env:USERPROFILE\Downloads", "$env:USERPROFILE\Desktop" `
        -Filter "Donatix_Server_Fix_v9_1*.zip" -File |
        Sort-Object LastWriteTime -Descending | Select-Object -First 1
    if (-not $zip) { throw "Сначала скачай архив в Загрузки или на рабочий стол." }
    $update = "$env:USERPROFILE\Desktop\Donatix_Server_Fix_v9_1"
    Expand-Archive -LiteralPath $zip.FullName -DestinationPath $update -Force
    Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass -Force
    & "$update\Apply_Server_Fix_v9_1.ps1" -Push
}
```

Скрипт работает в текущем PowerShell, проверяет файлы перед записью и обновляет только содержимое этого пакета. `.git`, Flutter, Android/iOS, подпись и Codemagic сохраняются. По умолчанию репозиторий — `C:\Users\user\Desktop\Donatix_Android_iOS_v4`; другое расположение указывается параметром `-Repo`.

## 2. Загрузить этот же ZIP на сервер

В Windows PowerShell найдите скачанный архив и загрузите его:

```powershell
$zip = Get-ChildItem "$env:USERPROFILE\Downloads", "$env:USERPROFILE\Desktop" `
    -Filter "Donatix_Server_Fix_v9_1*.zip" -File |
    Sort-Object LastWriteTime -Descending | Select-Object -First 1
if (-not $zip) { throw "Архив не найден." }
scp $zip.FullName root@2.29.11.118:/root/Donatix_Server_Fix_v9_1.zip
```

После успешной загрузки:

```powershell
ssh root@2.29.11.118
```

## 3. Установить дополнение

Уже на сервере, где приглашение `root@uways`:

```bash
python3 -m zipfile -e /root/Donatix_Server_Fix_v9_1.zip /root/Donatix_Server_Fix_v9_1
python3 /root/Donatix_Server_Fix_v9_1/Android_Server_Addon/update_orders_deletion.py --apply
```

Установщик проверяет текущую версию 64 Python-файлов, схему базы, активный сервис и установленные модули. Перед заменой он сохраняет копию кода дополнения. Выполняется один перезапуск `donatix`; выберите спокойное время. При неуспешном запуске предыдущий код дополнения восстанавливается автоматически. Основная база не откатывается: новые операции клиентов сохраняются.

Успех:

```text
Order history and account deletion activated: OK
Existing site, API, Google and FCM health checks: OK
```

При `STOP` сохраните вывод. Не заменяйте файлы сайта или контрольные хэши, чтобы обойти проверку.

Путь резервной копии выводится установщиком. Ручной откат только кода при необходимости:

```bash
python3 /root/Donatix_Server_Fix_v9_1/Android_Server_Addon/update_orders_deletion.py --rollback /var/backups/donatix-android/ТОЧНЫЙ_ПУТЬ_ИЗ_ВЫВОДА
```

Откат кода не восстанавливает удалённые аккаунты. Для завершения ожидающих заявок очистки потребуется снова включить эту версию обработчика.

## 4. Release APK/AAB

После успешной установки в Codemagic используйте `main` и существующий `android-release`. Flutter-изменения v9 уже находятся в GitHub; в пакете 9.1 они не переписываются. Получите подписанные release APK/AAB, установите APK на телефон с прежним ключом подписи.

Проверьте историю своего аккаунта: заказы, поиск, статусы, даты, следующую страницу. Удаление проверьте на отдельном пустом аккаунте: вход отключается сразу, очистка выполняется в фоне после короткой паузы и расчётов. Повторная регистрация через Google может создать новый пустой аккаунт; старые данные и баланс не возвращаются. Рабочий клиентский аккаунт для проверки удалять не нужно.

Внешняя страница удаления после установки: `https://donatix.tj/android/account-deletion`. Политика конфиденциальности и сведения Google Play должны отражать сохранение обезличенных расчётных записей и защитных платёжных отпечатков. Сроки хранения резервных копий, журналов и сообщений уже переданных Telegram/другим сервисам отдельно устанавливает владелец. Этот установщик внешними копиями не управляет.

## Проверка и пределы

Все 44 проверки дополнения прошли локально на полученных текущих Python-модулях с отдельными базами и фиктивными поставщиками; реальные платежи и удаление клиентских аккаунтов не выполнялись. Проверены история без HTML, аутентификация, Google/FCM, изоляция клиентов, новая поддержка, гостевые ключи, покупка в обработке, повторное зачисление, одновременная запись вложения и удаление, ежедневная уборка уведомлений, проверка установщика и откат только кода. Windows-скрипт проверен по структуре и контрольным суммам; запуск в настоящем Windows выполнит пользователь.

В локальной копии используются прежние шаблоны и медиа. Сравнение 69 прежних проверок сайта без дополнения и с ним дало одинаковый результат: 66 прошли, 3 имеют прежние несовпадения. Они ожидают доллары при нынешнем значении по умолчанию TJS, прежнее поведение повторного чека отклонённой заявки и отсутствующий локально `dc-guide.mp4`. Код этих функций не исправлялся и в пакет не включён.

Версия 9.1 подготовлена для установки; это не утверждение о выполненном развёртывании, готовой подписанной сборке или одобрении Google Play. Финальная установка и проверка телефона выполняются по шагам выше.

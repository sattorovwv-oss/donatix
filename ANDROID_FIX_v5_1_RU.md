# Donatix: исправление ошибки Codemagic

Этот архив дополняет уже установленное обновление v5. Полностью заменять папку проекта не нужно.

## Что исправлено

На странице админки «Посещаемость» текст в строке «Сейчас на сайте» и проценты в блоке «Воронка» могли выходить за доступную ширину при увеличенном шрифте. Теперь эти подписи ограничены шириной строки и переносятся.

Проверки вёрстки теперь выводят исходное сообщение Flutter об ошибке, а не только «Expected null / Actual FlutterError». Ошибки проверяются сразу после открытия экрана и после прокрутки.

## Как установить

1. Распакуйте `Donatix_Android_Fix_v5_1.zip`.
2. Скопируйте папку `Donatix_Flutter` из архива в `C:\Users\user\Desktop\Donatix_Android_iOS_v4`. Согласитесь на объединение папок и замену двух совпадающих файлов.
3. Не создавайте внутри проекта дополнительную папку `Donatix_Android_Fix_v5_1`. Существующий проект и его историю Git удалять не нужно.
4. Выполните команды в PowerShell:

```powershell
cd "C:\Users\user\Desktop\Donatix_Android_iOS_v4"
git add Donatix_Flutter/lib/screens/admin.dart Donatix_Flutter/test/android_regressions_test.dart
git commit -m "Fix traffic admin layout with large text"
git push origin main
```

5. В Codemagic нажмите `Start new build`, выберите ветку `main` и workflow `android-release` — `Donatix signed Android APK and Play AAB`.

## Проверка исправления

- Исходная ошибка воспроизведена на официальном headless-движке Flutter 3.35.4 с тестовыми шрифтами и настройками `--use-test-fonts --disable-asset-fonts`, которые применяет `flutter test`.
- После исправления: все 51 Flutter-проверка прошла в этом режиме.
- Повторный прогон с подключённым шрифтом приложения Onest: все 51 проверка прошла.
- Dart 3.9.2: анализ `lib` и `test` завершился без замечаний.

Папки сервера, установщик заказчика, нативная папка iOS, ключи и настройки Codemagic не изменены. Серверный архив повторно отправлять заказчику для этого исправления не требуется.

Архив содержит исходники, а не APK/AAB. Полная release-сборка после исправления должна быть запущена в Codemagic; её результат ещё не подтверждён. Проверка на настоящем Android-телефоне остаётся отдельным шагом.

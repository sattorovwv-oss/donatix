# Donatix Android: подключение к существующему сайту

Обновление v7 рассчитано на текущий https://donatix.tj. Android-клиент использует существующий REST API `/api/v1` и существующие формы сайта. Для Google-входа и FCM подготовлено отдельное дополнение `Android_Server_Addon`; оно не заменяет исходники сайта и не добавляет таблицы в его основную базу.

## Как установить обновление проекта

1. Сделайте копию своей папки проекта. Распакуйте этот архив поверх неё с заменой совпадающих файлов. Сохраните каталог `.git`, настройки Codemagic, собственные `google-services.json`, `key.properties` и ключ подписи. Не удаляйте проект перед копированием.
2. Flutter-файлы на сервер сайта не отправляются. Для Google и FCM отдельно подготовьте `Android_Server_Addon` по его `README_RU.md`. Оно требует проверки версии сайта, серверного Firebase-ключа, отдельной мобильной базы и изменения команды запуска через systemd drop-in. Не устанавливайте старую папку `server_patch`, не заменяйте сайт, его `.env`, базу или nginx.
3. В PowerShell, находясь в корне своего Git-проекта:

```powershell
git add Donatix_Flutter Android_Server_Addon codemagic.yaml ANDROID_EXISTING_API_RU.md
git commit -m "Add Android Google sign-in and FCM integration"
git push origin main
```

4. В Codemagic выберите новый коммит и `android-release`. Оставьте свой Firebase JSON, группу `donatix_android` и сертификат `donatix_upload`. Адрес `DONATIX_URL`: `https://donatix.tj`, без `/api` в конце. Если `DONATIX_BUILD_NUMBER` задан вручную, его число должно быть больше номера установленной/опубликованной сборки.
5. После успешной проверки получите подписанные `Donatix-release.apk`, `Donatix-release.aab` и `release-verification.json`. Установите новый APK на Android. Старая установленная версия автоматически не изменится.

## Авторизация и данные

Вход по email или логину и паролю, регистрация и проверка дополнительного кода используют существующие формы `/login`, `/register`, `/login/code`. Статус активности аккаунта подтверждает сайт. Для активного пользователя приложение получает/создаёт его собственный ключ `Donatix Android` через существующую страницу `/panel/api`. Это обычная операция с данными аккаунта; серверные исходники и структура базы не меняются.

Ключ не вшит в приложение. Сессия и личный ключ хранятся в защищённом хранилище. Нельзя подставлять ключ владельца в качестве общего ключа для всех клиентов. Не отзывайте ключ `Donatix Android`, пока есть незавершённая покупка: существующий сервер разделяет повторы заказов по API-ключам. Приложение блокирует восстановление покупки с другим ключом.

Каталог, цены, баланс, заказы, выдача, платежи и чеки используют действующий REST API. Поиск и даты заказов, фильтр транзакций, часовой пояс, ключи/webhook, поддержка, история входов, рефералы, Dcoin и управление ботами используют существующие страницы и формы. Админка продолжает открывать исходные административные страницы через имеющийся клиентский рендерер. Успех операции определяется ответом сайта; экран не заменяет отсутствующие ответы вымышленными данными.

Для новых аккаунтов остаётся действующий порядок активации владельцем. Наличие кнопки в приложении не отменяет прав доступа, ограничения тарифа, отключённый способ оплаты или недоступного поставщика на сайте.

## Покупки и потеря связи

Перед подтверждением клиент читает актуальную стоимость и баланс. Перед отправкой заказа стоимость проверяется повторно. Сервер v1 не поддерживает атомарную фиксацию цены между этой проверкой и списанием: полностью устранить этот короткий промежуток без изменения сервера невозможно.

Запрос сохраняется до получения результата. Повтор использует тот же персональный ключ и тот же `Idempotency-Key`. Корзина оформляет отдельные заказы с отдельными стабильными ключами. При восстановлении приложение предупреждает: если запрос уже выполнен, сервер вернёт результат; если он не дошёл, подтверждение может оформить покупку сейчас. Сначала проверьте историю. При смене ключа или удалённом товаре обратитесь в поддержку, не создавайте слепой повтор.

## Уведомления и ограничения

После установки дополнения приложение обнаруживает `/api/v1/android/config` и включает Google-вход, если исходные OAuth-ключи сайта настроены. Push включается при корректном серверном Firebase-ключе того же проекта, что у приложения. Устройство регистрируется с действующей cookie и CSRF; уведомления проверяют аккаунт и привязку к сессии. После выхода, смены аккаунта или отзыва сессии старые уведомления не показываются.

Дополнение читает существующие события сайта примерно раз в секунду и отправляет FCM. Android, Firebase, сеть и энергосбережение могут задерживать доставку. При подключённом дополнении резервная периодическая проверка использует те же ID, что FCM, чтобы не дублировать одно уведомление. При отсутствии дополнения сохраняется прежняя периодическая проверка заказов, пополнений и баланса. Просмотр значка и фоновая проверка не помечают сообщения сайта прочитанными. Открытие самого списка следует поведению сайта и отмечает их прочитанными.

Без установленного и настроенного дополнения недоступны:

- завершение Google-входа с передачей сессии обратно в нативное приложение; вход Google на самом сайте остаётся функцией сайта;
- мгновенная доставка FCM с сервера;

Даже после установки дополнения остаются недоступны:

- удаление аккаунта и его данных из приложения;
- атомарная серверная фиксация подтверждённой цены.

Папка `ios` сохранена. Этот выпуск проверяется для Android; готовность iPhone-версии им не подтверждается.

## Приёмка перед публикацией

Проверки кода и сборка не подтверждают реальную выдачу поставщиком. На настоящем Android нужно проверить: существующий и новый аккаунт, активацию, каталог/цену, пополнение с чеком и автоматический способ оплаты, один согласованный реальный заказ и его выдачу, ошибку/возврат, потерю связи и повтор, корзину, работу прав администратора и уведомления. Сравните баланс и историю с сайтом.

До Google Play отдельно завершите доступный пользователю способ удаления аккаунта и данных, страницу приложения, политику конфиденциальности, сведения о данных и соответствие реальных платежей правилам магазина. Этот архив сам по себе не является подтверждением готовности к публикации.

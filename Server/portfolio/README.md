# Alijon — 3D-портфолио

Личный сайт: Next.js 16 + React 19 + TypeScript + Three.js (React Three Fiber) +
GSAP + Framer Motion + Tailwind v4 + Lenis.

Собирается в обычные HTML/CSS/JS — **работает на любом хостинге, Node.js на
сервере не нужен**.

---

## Как выложить на хостинг (Somon Host, cPanel и любой другой)

```bash
npm install     # один раз
npm run build   # собрать
```

После сборки появится папка **`out/`**. Всё её содержимое загрузи в `public_html`
на хостинге — и сайт работает.

> Загружать нужно **содержимое** папки `out/`, а не саму папку.
> То есть `index.html` должен лежать прямо в `public_html/`.

## Что менять без программиста

Почти всё живёт в одном файле — **`config/site.ts`**:

| Что | Где в файле |
|---|---|
| Имя, никнейм, город | раздел `person` |
| Telegram, Instagram, GitHub, почта, телефон | раздел `contacts` |
| Список навыков | раздел `skills` |
| Проекты (год, стек, ссылка) | раздел `projects` |
| Фоновая музыка | раздел `audio` |
| Тяжесть 3D-сцены | раздел `scene` |

Тексты на трёх языках — в `lib/locales/`: `ru.ts`, `tg.ts`, `en.ts`.

После любых правок снова `npm run build` и заново залей `out/`.

### Телефон и Instagram

В `config/site.ts` сейчас стоят заглушки — **поменяй их на свои**:

```ts
{ id: 'phone',     display: '+992 000 00 00 00', href: 'tel:+992000000000' }
{ id: 'instagram', display: '@uways',            href: 'https://instagram.com/uways' }
```

### Таджикский перевод

Файл `lib/locales/tg.ts` переведён не носителем языка. Пройдись по нему и
поправь формулировки — менять нужно только текст в кавычках, структуру трогать
нельзя.

## Музыка

Браузеры запрещают автозапуск звука без действия пользователя — это не
обходится никак. Поэтому:

1. Положи файл в `public/audio/`, например `ambient.mp3`.
2. В `config/site.ts` укажи `audio.src = '/audio/ambient.mp3'`.
3. В интерфейсе появится кнопка включения звука.

## Форма заказа

Сейчас работает так: заявка форматируется, копируется в буфер обмена и
открывается чат в Telegram — остаётся вставить её одним движением. Причина в
том, что Telegram не умеет подставлять текст в личный чат по ссылке.

Когда подключим PHP-обработчик на хостинге, в `config/site.ts` нужно будет
поменять `orderTarget.mode` на `'php'` — заявки начнут приходить в бота
автоматически.

## Структура

```
config/site.ts          настройки: контакты, проекты, навыки
lib/
  i18n.tsx              три языка, определение языка браузера
  locales/              словари ru / tg / en
  useScrollProgress.ts  прогресс прокрутки для 3D-сцены
  softSprite.ts         текстура частиц (рисуется в браузере)
components/
  scene/                3D: город, земля, частицы, фигура, камера, эффекты
  sections/             экраны сайта
  ui/                   навигация, карточки, анимация появления
app/                    layout, страница, стили и дизайн-токены
public/fonts/           шрифты Exo 2 и Golos Text (локальные)
```

## Технические решения, о которых стоит знать

**Шрифты лежат локально, а не с Google Fonts.** Проверено парсером шрифтов: из
популярных гарнитур только **Golos Text** и **Exo 2** содержат все 12
таджикских букв (ғ ӣ қ ӯ ҳ ҷ). У Manrope, Onest, Unbounded и Rubik их нет —
таджикский текст рассыпался бы на квадраты.

**Город — один InstancedMesh.** Пара сотен отдельных мешей просадила бы кадры;
здесь это один вызов отрисовки, а окна рисует шейдер, без единой картинки.

**Карточки проектов наклоняются средствами CSS, а не отдельными 3D-сценами.**
Шесть канвасов на странице — это шесть контекстов WebGL и мёртвая
производительность.

**На мобильных меньше частиц и выключен bloom.** Стабильные кадры важнее
эффектов на слабом железе.

**Первый рендер всегда русский.** При статическом экспорте HTML собирается
один раз; если определять язык браузера сразу, разметка сервера и клиента
разойдутся и React выдаст ошибку гидратации. Поэтому язык переключается сразу
после загрузки страницы.

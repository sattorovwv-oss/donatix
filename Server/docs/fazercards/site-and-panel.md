# FazerCards — как устроены сайт и кабинет реселлера

Составлено по скриншотам с телефона (главная, вход, регистрация, документация,
кабинет). Это ориентир по **структуре**, а не по внешнему виду: дизайн, логотип
и тексты у нас должны быть свои.

## Общий стиль

- Светлый фон (почти белый), один акцентный цвет — фиолетовый (кнопки, активные пункты, цифры цен).
- Крупные жирные заголовки без засечек, серый поясняющий текст.
- Всё собрано из карточек: белые, большое скругление, тонкая рамка, лёгкая тень.
- Сначала телефон: одна колонка, меню-«гамбургер», плавающая кнопка «наверх».
- Переключатель языка RU/EN, в кабинете — ещё тёмная тема и колокольчик уведомлений.

## Публичный сайт

Меню: Каталог · Блог · Документация · ИИ-агенты · Для кого · О платформе ·
Услуги · Тарифы · FAQ. Кнопки: «Попробовать бесплатно» и «Вход в панель».

Главная сверху вниз: первый экран с макетом окна и примером API-ответа →
«Что входит в каждый тариф» → цифры (10000+ продуктов, 1000+ категорий, 24/7) →
каталог плашками → услуги (6 карточек с картинками) → блоки «проблема → решение» →
«Как это работает» в 4 шага → блок про API → пробный период → тарифы →
отзывы → ресурсы → FAQ → финальный призыв → большой подвал с SEO-ссылками
(«PUBG UC оптом» и т.п.), способами оплаты (Binance Pay, USDT) и Telegram.

Тарифы на сайте: Bronze $3.99, Silver $6.99, Gold $9.99 в месяц
(разница — в размере скидки, например на пополнение Steam 2,5% / 3% / 3,55%).

### Регистрация («Получить пробный период»)

Тариф (по умолчанию «Пробный период», 5 дней Gold, карта не нужна) · Email ·
Имя пользователя · Пароль (мин. 8 символов) · Повтор пароля → «Создать аккаунт».
Справа/ниже — список «что входит».

### Вход в панель

Вкладки «Панель V2 / Перенос / Панель V1» · Email · Пароль · «Забыли пароль?» ·
«Войти» · ссылка на пробный период · список «в панели вам доступны».

### Документация

Хлебные крошки «Документация › API Reference», карточки «Базовый URL» и
«Аутентификация», блок «Рецепты» (Cookbook), официальные SDK, ссылка на OpenAPI,
«Быстрый старт», тёмные блоки кода с кнопкой «копировать» и подписью языка.
Содержание API — в `api-reference.md`.

## Кабинет реселлера

### Боковое меню (разделы)

- **Обзор:** Главная · Заказы · Транзакции
- **Каталог:** Пополнить Steam · Steam Гифты · Telegram звёзды · Ключи игр ·
  Ручные услуги · Подарочные карты · Пополнение сервисов
- **Финансы:** Баланс
- **Дополнительно**
- **Аккаунт:** Статистика · Профиль (там API-ключ) · Настройки · Поддержка · Выйти

### Главная («Обзор»)

- Шапка «Панель реселлера / Обзор», кнопки «Пополнить баланс» и «Профиль».
- Логин и почта.
- Сводка тремя карточками: Всего потрачено · Всего заказов · Баланс (4 знака после точки).
- Карточка подписки: тариф, цена, «Активна», кнопка «Поменять».
- Быстрые действия: Заказы · Пополнение игр и сервисов · Подарочные карты · Пополнить Steam.
- Последние заказы + «Все заказы».
- Интеграции: FunPay — «Автоматическое выполнение заказов через FazerCards».

### Заказы

Поиск (номер или название) · фильтры «Статус» и «Тип заказа» · список карточек:
иконка сервиса, `ord-…`, сумма справа, «Сервис • товар for @получатель»,
значок статуса (зелёная галочка) и дата.

### Транзакции

Поиск (комментарий или `tx…`) · фильтры «Тип движения» и «Статус» · карточки:
`tx…`, «Charge for ord-…» или «BEP20 top-up for tx…», сумма красным (списание)
или зелёным (начисление), бейджи «Списание/Начисление» и дата.

### Страницы покупки (все по одной схеме: шаги слева → «Сводка» → «Продолжить»)

- **Пополнить Steam:** логин Steam (с проверкой) · сумма (мин./макс. в валюте) ·
  валюта USD/RUB/KZT/UAH · кнопка «Курсы». Сводка: скидка, получит на аккаунт,
  получит в USD, к оплате.
- **Steam Гифты:** 1 — игра (поиск по названию или AppID), 2 — издание,
  3 — регион и цена (поиск страны). Сводка: invite-ссылка s.team/p/…, App ID,
  ID пакета, издание, регион, цена.
- **Telegram:** вкладки «Звёзды / Premium». Звёзды: @username, количество
  (50–10000), готовые пакеты 50/100/200/250… с ценой. Premium: @username,
  планы 3/6/12 месяцев. Сводка: аккаунт, план, к оплате.
- **Ключи игр:** поиск, фильтры «Платформа» и «Регион», избранное; сетка
  карточек с обложкой, названием и бейджами (Steam, GLOBAL/СНГ/ROW).
- **Ручные услуги:** поиск и избранное; большие карточки с обложкой
  (например «Xbox Loaded Accounts (US)», «Call of Duty Mobile»), бейдж
  «Временно недоступно».
- **Подарочные карты:** поиск по категории и избранное; сетка карточек брендов
  с регионом в названии (App Store & iTunes US/RU/TR, PUBG Mobile…).

## Выводы для нашего проекта

1. Наш кабинет можно строить по тем же разделам: они уже совпадают с группами
   их API (topups, giftcards, gamekeys, steam, telegram, manual-services).
2. Везде одна схема покупки «шаги → сводка → продолжить», поэтому её стоит
   сделать один раз и переиспользовать для всех товаров.
3. Цены показываются с 4 знаками после точки, и у нас нужно так же: наценка
   в доли цента на объёме важна.
4. Нужен собственный API-ключ для каждого нашего клиента (как «Профиль» у них)
   и журнал транзакций с понятными подписями «Charge for ord-…».
5. Интеграция с маркетплейсами (у них FunPay) — хорошая идея на потом.

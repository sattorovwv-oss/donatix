# 🤖 Телеграм-бот: память по деньгам и накладным

Бот слушает голосовые сообщения, запоминает переводы и оплаты, хранит фото накладных
и по просьбе присылает PDF-отчёт. Всё по-русски, живой речью — без форм и кнопок.

## Что он умеет

**Запомнить** — говоришь голосом или пишешь:

> «Сегодня отправил Абубакру три тысячи сомони»
> «Оплатил за товар сумки, четыре места, 500 тысяч тенге, деньги должен через 10 дней»

Бот разбирает: кому, сколько, в какой валюте, за что, сколько мест, когда срок — и сохраняет.
В ответ присылает карточку с кнопками **✏️ Исправить** и **🗑 Удалить**.

**Вспомнить** — спрашиваешь через месяц:

> «Какие деньги я отправил Абубакру?» → перечислит **всю историю** с датами и суммами
> «Какого числа я отправил деньги Абубакру?»
> «Сколько я оплатил за сумки?»

**Накладные** — присылаешь фото, потом говоришь:

> «Это накладная от женской обуви»

Через два дня, когда товар пришёл:

> «Отправь накладную от женской обуви» → бот находит то самое фото и присылает

**Напомнить** — говоришь, когда именно:

> «Напомни мне 15 сентября в три часа дня позвонить Абубакру»

15.09 в 15:00 приходит: **⏰ Позвонить Абубакру** — с кнопками «✅ Сделано» и
«⏰ Отложить на день».

Понимает и «через сколько», и «когда именно»:

| Скажешь | Придёт |
|---|---|
| «через 30 секунд» | через 30 секунд |
| «через 5 минут», «через полчаса», «через два часа» | точно тогда |
| «завтра в три часа дня» | завтра в 15:00 |
| «послезавтра утром» | через два дня в 9:00 |
| «15 сентября в полвосьмого вечера» | 15.09 в 19:30 |

Время из речи: «в три часа дня» = 15:00, «утром» = 9:00, «в обед» = 13:00,
«вечером» = 19:00. Не назвал время — придёт в 9 утра.

**О сроках напоминает сам** — просить не надо:

> «Оплатил за сумки 500 тысяч тенге, должен отдать через 10 дней»

За день до срока и в сам день придёт: **⏰ Завтра срок: Абубакр · 500 000 KZT за «сумки»**.
Если срок прошёл, а долг не закрыт — напомнит раз в сутки, пока не скажешь «закрыто».

Ещё напомнит **проверить товар** («товар придёт через два дня») и **подписать фото**,
если прислал накладную и забыл сказать, что это.

**Отчёт** — PDF файлом:

> «Сделай отчёт с 1 августа по сегодня»

В отчёте: итоги **по каждой валюте отдельно** (сомони, тенге, рубли — без пересчёта
по курсу, чтобы ничего не переврать), таблица всех операций и список несгоревших сроков.

## Что нужно перед запуском

Три ключа:

| Ключ | Где взять | Зачем |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | [@BotFather](https://t.me/BotFather) → `/newbot` | сам бот |
| `OPENAI_API_KEY` | [platform.openai.com/api-keys](https://platform.openai.com/api-keys) | распознавание голоса (Whisper) |
| `ANTHROPIC_API_KEY` | [console.anthropic.com](https://console.anthropic.com/settings/keys) | понимание смысла (Claude) |

И свой Telegram id — узнать у [@userinfobot](https://t.me/userinfobot).
**Бот отвечает только этому id**, иначе посторонние потратят твои ключи и увидят твои деньги.

## Установка — одна команда

```bash
git clone https://github.com/alijon26062006-bit/AlijonMahmadjonov.git && cd AlijonMahmadjonov && bash setup.sh
```

Дальше мастер сам:

1. поставит Python-окружение, зависимости и шрифт для кириллицы;
2. спросит **токен бота** — и сразу проверит его, назвав имя твоего бота;
3. **сам определит твой Telegram id** — просто напишешь боту любое сообщение,
   искать id у @userinfobot не надо;
4. спросит **ключ OpenAI** и **ключ Anthropic** — каждый проверит на месте
   и скажет отдельно, если ключ неверный, и отдельно — если на счёте нет денег;
5. предложит настроить автозапуск, чтобы бот сам поднимался после перезагрузки;
6. запустит бота.

Ключи нужно приготовить заранее:

| Что | Где взять |
|---|---|
| Токен бота | [@BotFather](https://t.me/BotFather) → `/newbot` |
| Ключ OpenAI | [platform.openai.com/api-keys](https://platform.openai.com/api-keys) |
| Ключ Anthropic | [console.anthropic.com](https://console.anthropic.com/settings/keys) |

Мастер можно запускать сколько угодно раз: если ключи уже введены, он покажет их
скрытыми и спросит, менять или оставить.

Записываются ключи в файл `.env` с доступом только владельцу — другие пользователи
сервера прочитать его не смогут.

### Если что-то пошло не так

**`No module named 'bot'`** — ты не в той папке. Проверь `pwd`: нужно быть внутри
`AlijonMahmadjonov`.

**`В токене посторонние символы`** — при копировании из чата прилипла кириллическая
буква или неразрывный пробел. Скопируй заново, целиком.

**`нет денег`** — ключ правильный, но счёт пустой. Пополни баланс у того сервиса,
который назван в сообщении.

### Установка вручную

Если хочешь по шагам, без мастера:

```bash
git clone https://github.com/alijon26062006-bit/AlijonMahmadjonov.git
cd AlijonMahmadjonov

apt install -y fonts-dejavu-core          # шрифт для кириллицы в PDF

python3 -m venv .venv
source .venv/bin/activate                 # на Windows: .venv\Scripts\activate
pip install -r requirements.txt

cp .env.example .env
nano .env                                 # вписать три ключа и свой id
python -m bot.main
```

## Запуск

```bash
python -m bot.main
```

Бот пишет в лог своё имя и id, которым отвечает. Останавливается по `Ctrl+C`.

### Чтобы работал постоянно (systemd)

`bash setup.sh` предлагает настроить это сам. Вручную — создай
`/etc/systemd/system/moneybot.service`:

```ini
[Unit]
Description=Telegram money bot
After=network-online.target

[Service]
Type=simple
User=root
WorkingDirectory=/root/AlijonMahmadjonov
ExecStart=/root/AlijonMahmadjonov/.venv/bin/python -m bot.main
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
```

Если бот стоит в другом месте или работает под другим пользователем — поменяй эти
три строки: `User`, `WorkingDirectory` и `ExecStart`.

```bash
systemctl daemon-reload
systemctl enable --now moneybot
systemctl status moneybot           # работает или нет
journalctl -u moneybot -f           # смотреть логи вживую
```

## Обновление

Когда в коде что-то поменяется:

```bash
cd /root/AlijonMahmadjonov
git pull
source .venv/bin/activate && pip install -r requirements.txt
systemctl restart moneybot          # если настроен автозапуск
```

Папка `data/` при обновлении не трогается — все записи и накладные остаются на месте.

## Проверка без Telegram

```bash

python -m bot.selftest --keep "отправил Салиму 200 сомони"   # разобрать одну фразу
```

`selftest` работает на временной базе — твои настоящие данные не трогает.

## Где лежат данные

Всё в папке `data/` рядом с проектом (в git не попадает — она в `.gitignore`):

```
data/bot.db        база: пользователи, операции, документы, напоминания, журнал
data/photos/       фото накладных
data/reports/      готовые PDF
```

**Резервная копия — это просто копия папки `data/`.** Останови бота, скопируй папку, запусти обратно.

## Как это устроено

```
Telegram
  ├─ голос ─→ Whisper ──┐
  ├─ текст ─────────────┼─→ Claude решает, что делать ──→ инструменты ──→ SQLite
  └─ фото ─→ на диск ───┘                                      ├─→ PDF-отчёт
                                                               └─→ фото обратно в чат
```

| Файл | Что делает |
|---|---|
| `setup.sh` | установка одной командой |
| `bot/setup.py` | мастер: спрашивает и проверяет ключи |
| `bot/main.py` | запуск, long polling |
| `bot/handlers.py` | обработчики Telegram: голос, текст, фото, кнопки, команды |
| `bot/stt.py` | голос → текст через Whisper |
| `bot/brain.py` | цикл tool use с Claude |
| `bot/schemas.py` | описания инструментов для Claude |
| `bot/prompts.py` | системный промпт и контекст хода |
| `bot/tools.py` | реализации инструментов (чистые функции над базой) |
| `bot/access.py` | кто пускается в бота (middleware) |
| `bot/admin.py` | панель `/admin` |
| `bot/db.py` | SQLite + поиск с учётом русских словоформ |
| `bot/reminders.py` | планировщик напоминаний |
| `bot/reports.py` | PDF через reportlab |

Поиск понимает словоформы: «сумки» находит «сумка», «обуви» находит «обувь» —
через FTS5 с обрезкой до корня, с запасным поиском по подстроке.

## Команды в чате

| Команда | Что делает |

## Время и часовой пояс

`/vremya` показывает, который сейчас час по мнению бота:

```
Сейчас у тебя: 31.08.2026, 17:32
Часовой пояс: Душанбе (UTC+5)
Напоминания о сроках: в 9:00

[🇹🇯 Душанбе]  [🇰🇿 Алматы]
[🇺🇿 Ташкент]  [🇷🇺 Москва]
```

Таджикистан, Казахстан и Узбекистан живут по UTC+5 — по умолчанию стоит именно он.
Пояс **у каждого пользователя свой**: кнопкой или командой `/vremya Asia/Almaty`
(подойдёт любое имя пояса, не только из списка кнопок).

`/vremya 7` — во сколько присылать автоматические напоминания о сроках.
Те, что ты просишь голосом, приходят в названное тобой время.

## Несколько пользователей

Ботом может пользоваться не только владелец. **У каждого свой отдельный учёт:**
свои операции, свои накладные, свои отчёты. Чужого никто не видит — ни в поиске,
ни в отчёте.

### Как дать человеку доступ

1. Открой `/admin` → **➕ Добавить по ID** → пришли его Telegram id числом.
2. Скажи ему открыть бота и нажать **Старт**.
3. Бот спросит имя, человек ответит — и сразу работает.

**Не знаешь его id?** Пусть просто напишет боту. Тебе придёт уведомление
«К боту постучался незнакомый человек, id 123456789» с кнопкой **➕ Дать доступ** —
нажимаешь, и всё. Набирать число руками не надо.

Кто не добавлен — работать не может и твоих денег на Whisper и Claude не тратит.

### Панель

```
Пользователи (3)

✅ Алиджон · id 111 · админ · 128 записей · был сегодня
✅ Салим · id 222 · 14 записей · был вчера
⏳ id 333 · приглашён, ещё не заходил

[➕ Добавить по ID]  [🔄 Обновить]
```

Нажми на человека — откроется карточка с кнопками **🚫 Заблокировать**,
**✅ Разрешить** и **🗑 Удалить вместе с данными** (спросит подтверждение —
это необратимо).

В панели видно **имена, id и сколько у кого записей**, но не сами чужие операции:
деньги и накладные других людей остаются закрытыми.

Себя заблокировать или удалить нельзя — иначе можно остаться без управления ботом.

### Кто владелец

Владельцы — те, чьи id стоят в `ALLOWED_USER_IDS` в `.env`. При первом запуске
они заводятся в базе как админы. Дальше всё управление идёт через `/admin`,
лезть в `.env` и перезапускать бота больше не нужно.

## Настройки в `.env`

| Переменная | По умолчанию | Что значит |
|---|---|---|
| `TZ` | `Asia/Dushanbe` | часовой пояс — от него считается «сегодня» и «через 10 дней» |
| `DEFAULT_CURRENCY` | `TJS` | валюта, если в речи её не назвали |
| `ANTHROPIC_MODEL` | `claude-opus-5` | модель Claude |
| `MAX_VOICE_SECONDS` | `300` | максимальная длина голосового |
| `DATA_DIR` | `data` | где хранить базу и файлы |
| `LOG_LEVEL` | `INFO` | `DEBUG` — если что-то не работает |

## Сколько это стоит

Примерно за одно сообщение:

- распознавание голоса (Whisper) — около $0.006 за минуту записи;
- разбор смысла (Claude Opus 5) — обычно 1–3 цента.

То есть при 30 сообщениях в день выходит порядка $10–20 в месяц. Точные цены смотри
на сайтах OpenAI и Anthropic — они меняются. Если захочешь дешевле, поменяй
`ANTHROPIC_MODEL` в `.env` на `claude-sonnet-5` — понимать будет чуть хуже,
но заметно дешевле.

## Если что-то не работает

**Бот молчит на всё, даже на `/start`** — значит процесс не запущен. Живой бот молчать
не может: он отвечает даже незнакомцу («у тебя нет доступа, твой id …»). Чаще всего так
бывает, когда бот запускали руками в терминале, а потом отключились от сервера.

```bash
cd /root/AlijonMahmadjonov && bash setup.sh
```

На вопрос «Ввести ключи заново?» отвечай **н**, на «Настроить автозапуск?» — **д**.
После этого бот поднимается сам и после перезагрузки, и после падений.

Если автозапуск уже настроен:

```bash
systemctl restart moneybot && systemctl status moneybot --no-pager
```

Собрать всю картину разом (ключи не показывает — только есть они или нет):

```bash
cd /root/AlijonMahmadjonov && bash -c '
echo "=== СЕРВИС:"; systemctl is-active moneybot 2>/dev/null || echo "  не настроен"
echo "=== ПРОЦЕСС:"; pgrep -af "[b]ot\.main" || echo "  НЕ запущен"
echo "=== GIT:"; git log --oneline -1; git status --short | head -5
echo "=== .env:"; for k in TELEGRAM_BOT_TOKEN ALLOWED_USER_IDS OPENAI_API_KEY ANTHROPIC_API_KEY; do
  grep -qE "^$k=.+" .env 2>/dev/null && echo "  $k: есть" || echo "  $k: НЕТ"; done
echo "=== КОД:"; .venv/bin/python -c "import bot.main; print(\"  импортируется\")" 2>&1 | tail -5
echo "=== ЛОГИ:"; journalctl -u moneybot -n 30 --no-pager 2>/dev/null || echo "  логов нет"
'
```

**«Не заданы обязательные настройки»** — не заполнен `.env`. Скопируй `.env.example` и впиши ключи.

**Бот молчит на все сообщения** — твой id не совпадает с `ALLOWED_USER_IDS`. Проверь у [@userinfobot](https://t.me/userinfobot).

**«Не найден шрифт с кириллицей»** — `sudo apt install fonts-dejavu-core`, или пропиши свой путь в `FONT_PATH`.

**Бот неправильно расслышал сумму** — нажми **✏️ Исправить** под карточкой и скажи, как надо.

**Напоминание не пришло вовремя** — проверь, что бот работал: `systemctl status moneybot`.
Пока он лежал, напоминания копятся и приходят при запуске с пометкой, на когда были
назначены. Старее трёх дней не присылаются, но видны в `/napominaniya`.

**Напоминание пришло не в то время** — открой `/vremya`. Первая строка показывает время
так, как его видит бот: сверь с телефоном. Не сходится — выбери свой пояс кнопкой.

**Не находит старую запись** — попробуй другими словами или без имени: распознавание
часто портит имена, и в базе может лежать «Абубакир» вместо «Абубакр».

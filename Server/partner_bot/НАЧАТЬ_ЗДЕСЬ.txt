ШАБЛОН МАГАЗИНА-БОТА: звёзды, Premium, игры, Steam, API для разработчиков

В этой копии нет ни одного ключа, токена и ID. Всё, что нужно
заполнить, собрано в файле .env.example — строки с пустым значением
после знака «=».

─────────────────────────────────────────────────────────────
АКТИВАЦИЯ — ТРИ ЗНАЧЕНИЯ, ОДНА КОМАНДА

  1. Токен бота            — у @BotFather (/newbot)
  2. Ваш Telegram ID       — у @userinfobot (только цифры)
  3. Ключ поставщика       — X-API-Key из кабинета FazerCards

Загрузите архив на сервер (Ubuntu) и выполните:

  unzip stars_bot_template.zip
  cd stars_bot_template
  sudo bash install.sh

Или сразу, без вопросов:

  sudo bash install.sh ТОКЕН ID_АДМИНА КЛЮЧ_ПОСТАВЩИКА

Интернет нужен только для библиотек Python — сам код берётся из
этого архива, GitHub не нужен.

Установщик задаст эти три вопроса, сам проверит токен в Telegram и
ключ у поставщика, сам поставит поставщика и запустит бота. Через
минуту бот напишет вам: «✅ Бот активирован» — и что ещё задать.

Один ключ поставщика работает на всё: звёзды, Premium, игры и API.

Без реквизитов карты бот тоже работает — просто пополнение картой у
клиентов отвечает «скоро». Задайте их: /panel → 💳 Реквизиты.

─────────────────────────────────────────────────────────────
ЧТО НАСТРАИВАЕТСЯ ИЗ АДМИН-ПАНЕЛИ, БЕЗ ФАЙЛОВ

  /panel → 💳 Реквизиты          номер карты, получатель, банк
  /panel → 🤝 Партнёры           доли партнёров, взносы и выплаты
  /panel → 🏦 Оплаты банка        приём оплаты: что пришло и куда
  /panel → 💵 Цены и наценка      цены, наценка, курс доллара, автоцены
  /panel → 🕹 Игры                какие игры продавать, ключ поставщика игр
  /panel → 🧩 API                 наценка и ключи для разработчиков
  /panel → 💳 Балансы ключей      остатки у поставщика, запросов в минуту
  /panel → 👮 Доступ к панели     добавить админа по ID
  /panel → 📢 Подписка на канал   обязательная подписка

─────────────────────────────────────────────────────────────
АВТОПЛАТЁЖ — ОДИН ШАГ НА СЕРВЕРЕ

Приём оплаты работает сам: клиенту называется сумма с копейками
(например 100.04), банк присылает уведомление, бот узнаёт по копейкам,
чей это перевод, и зачисляет. Владелец ничего не подтверждает.

Чтобы бот видел уведомления банка, он один раз входит в ваш Telegram.
Для этого нужен код из SMS, поэтому этот шаг делается на сервере:

  sudo stars-bot userbot keys API_ID API_HASH   (ключи с my.telegram.org)
  sudo stars-bot userbot bank ИМЯ_БОТА_БАНКА
  sudo stars-bot userbot login                  (придёт код в Telegram)
  sudo stars-bot userbot start

После этого — всё автоматически.

─────────────────────────────────────────────────────────────
УПРАВЛЕНИЕ ПОСЛЕ УСТАНОВКИ

  Обновить до новой версии: распакуйте новый архив и в его папке
  снова  sudo bash install.sh  — настройки и база сохранятся.

  sudo stars-bot activate    сменить токен, ID админа или ключ
  sudo stars-bot status      работает ли
  sudo stars-bot logs        смотреть работу живьём

Один сервер — один бот: установщик не даст затереть уже
работающего бота чужим токеном. Второй бот — на другой сервер.

─────────────────────────────────────────────────────────────
БЕЗОПАСНОСТЬ

  • Файл .env и папку data/ никогда не выкладывайте и не пересылайте:
    в них ключи, база клиентов и вход в ваш Telegram.
  • Ключи не присылайте в переписку — ни людям, ни ботам.
  • Если ключ где-то засветился — выпустите новый у поставщика.

curl -s -X POST {{ base_url }}/api/v1/orders \
  -H "X-API-Key: $KEY" \
  -H "Idempotency-Key: $(uuidgen)" \

  -d '{"product_id": "tg-stars", "quantity": 100, "fields": {"telegram_username": "@player"}}'
{"ok": true, "order": {

  "product_name": "Telegram Stars 100", "quantity": 100,
  "total_usd": "1.6605", "delivery": null, "error": null
}}

ID товаров

Каждый товар и каждый пакет имеет свой product_id — его вы передаёте в POST /orders. По виду ID сразу понятно, что это за товар:

Товарproduct_idПример
Пополнения игр (Free Fire, PUBG Mobile и др.)topup- + 10 знаковtopup-3f9a1c2b7d
Подарочные картыgc- + 10 знаковgc-8b21e0d4a6
Ключи игрgk- + 10 знаковgk-5c0f7a9e13
Telegram Starsпостоянныйtg-stars
Telegram Premiumпо сроку, в месяцахtg-premium-3 tg-premium-6 tg-premium-12
Пополнение Steamпостоянныйsteam-topup

Примеры topup-… выше — условные. У каждой игры и каждого пакета (100 алмазов, 310 алмазов, недельный ваучер…) свой ID; настоящие берите из GET /products. ID не меняется, пока пакет есть в продаже, — его можно сохранить у себя и не запрашивать каталог перед каждым заказом.

1Найти игру

curl -s "{{ base_url }}/api/v1/categories" -H "X-API-Key: $KEY"

В ответе у каждой игры есть category_id — по нему удобно брать только её пакеты.

2Получить пакеты и их ID

curl -s "{{ base_url }}/api/v1/products?kind=topup&q=free%20fire" -H "X-API-Key: $KEY"
{"ok": true, "items": [{
  "product_id": "topup-3f9a1c2b7d",
  "kind": "topup", "category_id": "free_fire", "category_name": "Free Fire",
  "region": "CIS", "region_title": "СНГ",
  "name": "100 Diamonds", "title": "100 алмазов", "emoji": "💎",
  "price_usd": "0.9900",
  "fields": [{"key": "player_id", "label": "ID игрока", "type": "text"}]
}]}

Смотрите на region: у одной игры бывают пакеты для разных регионов (например, Free Fire СНГ и Индонезия) — у них разные ID, и пакет другого региона на аккаунт не зачислится.

3Заказать пакет по его ID

curl -s -X POST {{ base_url }}/api/v1/orders \
  -H "X-API-Key: $KEY" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d '{"product_id": "topup-3f9a1c2b7d", "fields": {"player_id": "1234567890"}}'
Бот в формате FazerCards (API v2). Там пакет передаётся как offer_id — в него ставится тот же product_id (topup-…), а в category_id — category_id игры: POST /api/v2/topups/order с телом {"category_id": "free_fire", "offer_id": "topup-3f9a1c2b7d", "fields": {"player_id": "1234567890"}}. Список пакетов в этом формате — GET /api/v2/topups/offers?category_id=….

Проверка аккаунта

Для многих игр можно проверить ID до заказа и показать покупателю ник. Заказ на несуществующий аккаунт не создаётся, деньги не списываются.

curl -s -X POST {{ base_url }}/api/v1/accounts/check \
  -H "X-API-Key: $KEY" -H "Content-Type: application/json" \
  -d '{"product_id": "topup-a1b2c3d4e5", "fields": {"player_id": "5123456789"}}'
{"ok": true, "supported": true, "valid": true, "player_name": "Player_6789", "region": "GLOBAL"}

Webhook

Адрес указывается в панели → API. При смене статуса заказа придёт:

POST https://your-site.com/donatix-hook
X-Donatix-Timestamp: 1767225600
X-Donatix-Signature: 5d41402abc4b2a76b9719d911017c592

{"event": "order.updated", "order": {"order_id": "dx-1042", "status": "completed"}}

Подпись — HMAC-SHA256 от timestamp + "." + тело вашим секретом. Ответьте 2xx, иначе повторим до 5 раз.

import hmac, hashlib

def valid(secret: str, timestamp: str, body: bytes, signature: str) -> bool:
    mac = hmac.new(secret.encode(), timestamp.encode() + b"." + body, hashlib.sha256)
    return hmac.compare_digest(mac.hexdigest(), signature)

Примеры

import uuid, requests

API = "{{ base_url }}/api/v1"
H = {"X-API-Key": "dx_live_..."}

def buy_stars(username: str, amount: int) -> dict:
    r = requests.post(f"{API}/orders", headers={**H, "Idempotency-Key": str(uuid.uuid4())},
                      json={"product_id": "tg-stars", "quantity": amount,
                            "fields": {"telegram_username": username}}, timeout=30)
    data = r.json()
    if not data["ok"]:
        raise RuntimeError(data["error"])
    return data["order"]
const res = await fetch("{{ base_url }}/api/v1/orders", {
  method: "POST",
  headers: { "X-API-Key": process.env.DONATIX_KEY, "Idempotency-Key": crypto.randomUUID(),
             "Content-Type": "application/json" },
  body: JSON.stringify({ product_id: "tg-stars", quantity: 100,
                         fields: { telegram_username: "@player" } }),
});
const data = await res.json();
if (!data.ok) throw new Error(data.error);
